## 📈 **Что это за эпик проэкт?**  
TaskMaster — это таск-трекер на котиках! Добавляй таски, дели на подзадачи, ставь дедлайны, чатайся с тимой и смотри дашборд с прогрессом. Не как эти скучные Trello/Jira — наш с **приколами из 2017**: таски "эксплодят" в конфетти при завершении, уведомления с голосом "ЙАААА РЕДИ!" из Пеппа Порченного, и рандомные мемы в комментах.  

**Фичи, которые взорвут твой мозг (как fidget spinner на 1000 RPM):**  
- ✅ **Drag'n'Drop доски** — тащи таски, как Даня тащит мемы из 2017.  
- ✅ **Реал-тайм коллаб** — изменения видны мгновенно, лолкек.  
- ✅ **AI-бот "Harambe Helper"** — предлагает таски: "Эй, Семён, сожри кебаб и закоммить!" 🤖🐒  
- ✅ **Мемы-интеграция** — прикрепляй GIF из 2017 (Distracted Boyfriend для багов).  
- ✅ **Статистика с лутбоксами** — завершил 10 тасков? Получи "эпик вин" значок! 🎁  
- ❌ **Баги?** Нет, только "фичи в разработке", как в 2017 на ВК-группах.
