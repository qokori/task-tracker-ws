# Task Tracker

**Task Tracker** — веб-сайт(без фронтенда) для управления задачами, которое помогает командам эффективно организовывать работу, отслеживать прогресс и анализировать продуктивность.

##  Основные возможности

### Авторизация
- Создание учетной записи
- Просмотр своего профиля с задачами
- Изменение профиля

### Управление задачами
- Создание задач с подробным описанием, вложениями, чек-листами и комментариями
- Разбивка крупных задач на подзадачи (subtasks)
- Назначение ответственных исполнителей и наблюдателей
- Установка дедлайнов и приоритетов (низкий, средний, высокий, критический)

### Визуализация процессов
- **Списки задач** (Kanban-доски, To-Do списки)
- **Календарный вид** для планирования по датам
- Drag & Drop для изменения статусов задач

### Коммуникация и контроль
- Обсуждение задач прямо в карточках с упоминаниями (@username)
- Умные уведомления о приближающихся дедлайнах и изменениях
- Полная история правок с возможностью просмотра версий

### Аналитика и интеграции
- Отчеты по продуктивности и загрузке сотрудников
- Встроенный учет времени (time tracking)
- Экспорт данных в PDF/Excel
